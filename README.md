# NexVain

轻量级农业专题数据展示与静态发布系统。

## 运行

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

打开 http://127.0.0.1:8000/admin 进入管理后台，http://127.0.0.1:8000/ 查看展示站点。

## 设计

- 专题：设计专题首页并关联多个 dcell。
- dcell：独立维护数据集展示内容，可以关联多个专题。
- 外观：全局主题统一控制展示风格。
- 静态发布：生成独立的 published/ 目录，部署到普通静态 Web 服务即可。

运行数据（SQLite、上传素材、发布产物）不纳入版本控制。

> 初始版本为本地开发原型。正式公开部署前应增加管理员身份认证、上传安全检查和发布审核，不要将管理服务直接暴露公网。
