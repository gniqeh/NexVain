# NexVain

面向农业大屏的专题库与 dcell 内容管理系统（开发原型）。

## 快速启动（Python 3.11+）

```bash
git clone https://github.com/gniqeh/NexVain.git
cd NexVain
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

- 管理后台：<http://127.0.0.1:8000/admin>
- 静态大屏：<http://127.0.0.1:8000/>（首次需要在后台点击「发布静态站点」）

## 使用顺序

1. 在「专题管理」创建一级专题，进入「设计首页」。
2. 在「dcell 管理」创建独立的 dcell，选择起始模板并编辑页面。
3. 回到专题编辑，勾选要关联的 dcell，设置可选的导航别名。
4. 在「外观设置」选取全局主题。
5. 点击「发布静态站点」，生成 `published/` 静态文件。

同一 dcell 可以被多个专题引用，不复制数据集页面。

## 技术

FastAPI + SQLite + GrapesJS + HTML/CSS/JavaScript。SQLite 文件自动创建于 `data/nexvain.sqlite3`。

## 当前原型的限制

- 管理 API 已增加可选 HTTP Basic Auth，未设置密码时仅允许本地访问。仍不建议直接暴露公网；生产环境应部署 HTTPS、独立管理域和完整鉴权。
- GrapesJS 编辑器当前通过外部 CDN 加载；断网时回退为 HTML 文本编辑。离线部署需将编辑器依赖打包到本地；已发布 SVG 图表和 PNG 图片离线可用。
- 现在支持图片上传（图片重新编码为 PNG，剥离 EXIF），以及通过输入名称/数值生成柱状图、折线图 SVG，并将其插入页面。图表目前为静态 SVG，不是 ECharts 交互图表。地图、复杂模板还未接入。
- 发布过程保留白名单 HTML/CSS 属性，不支持任意脚本；编辑器中的部分高级样式和交互可能不能输出。发布生成的 SVG 和 PNG 文件与静态站点一同复制。
- 当前是 **可运行代码原型，并非经过完整部署验收的生产版本**。上线前还需完善登录、数据校验、素材脱敏审查和发布隔离。
- `published/` 为导出静态站点，可以单独部署到 Nginx；管理服务和 SQLite 不需要一起部署。

## 本地测试

```bash
pip install -r requirements-dev.txt
pytest -q
```

此仓库已配置 GitHub Actions 进行基础语法和接口测试。

## dcell 外部页面挂载（开发版）

允许绕过 GrapesJS，直接上传自己制作的静态网站。操作：

1. 创建 dcell，在「页面来源」选择「外部静态页面包 ZIP」，保存。
2. 将网页目录打成 ZIP，ZIP 根目录必须有 `index.html`。内部可以有 `css/`、`js/`、`images/`、`data/`。
3. 上传 ZIP，后台保存到 `data/packages/<dcell_id>/`；可预览。
4. 点击发布，文件会出现在 `published/custom/dcell-<id>/`，在 dcell 展示页中以 `iframe sandbox="allow-scripts"` 加载。

也支持**服务器已有目录导入**，供 Python/Jupyter 自动生成的静态页面使用。先配置：

```bash
export NEXVAIN_IMPORT_ROOT=/home/youruser/nexvain_pages
```

然后在 dcell 编辑窗口输入相对于此根目录的子目录名，点击「导入服务器目录」。系统会校验路径后复制页面文件，杜绝任意读取服务器其他位置。原目录修改后需要重新导入并发布。

示例项目：`examples/wild-dcell/`，可以自行压缩其中的文件上传。

单 ZIP 不超过 50MB，最多 300 文件，单文件不超过 15MB（解压后总量也不超过 50MB）。只允许静态网页常用扩展名，拦截路径穿越及符号链接。

**安全说明：** ZIP 是可执行 HTML/JS。只导入可信来源，提前脱敏，不要上传原始科研数据。页面默认嵌入 sandbox iframe，可能限制一些需要同源访问、弹窗或第三方网络接口的功能。正式面向公网运行时，建议让自定义页面使用独立静态域名，不要把管理接口与不可信 HTML 放在同一安全域。

## 管理员访问

默认仅供本机 `127.0.0.1` 使用，远程访问管理 API 必须设置环境变量。示例：

```bash
export NEXVAIN_ADMIN_USER=admin
export NEXVAIN_ADMIN_PASSWORD='替换为高强度密码'
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

后台采用浏览器 HTTP Basic Auth。公网部署需要 HTTPS、反向代理防护和更完整的鉴权与审计，不能把开发服务直接暴露出去。

## 本轮新增

- 进入「设计页面」可上传 JPG/PNG/WebP（每张最高 10MB、解码不超过 3000 万像素），服务器重新编码为 PNG，删除照片 EXIF 信息。
- 可输入两列「名称,数值」，生成柱状图或折线图并插入专题/dcell 页面。SVG 文件可随发布结果复制到静态服务器。
- 这些统计图为静态 SVG，尚不支持 ECharts 悬浮提示或缩放。
- 全部上传图片请先检查是否包含可见敏感信息；去 EXIF **不等于**完成业务脱敏。

## 专题导航为何没有出现刚导入的 dcell？

导航是**发布时生成的静态文件**，不是管理后台实时列表。必须依次完成：导入 dcell → 在专题编辑界面勾选它并点击「保存关联」→ 点击右上角「发布静态站点」→ 重新打开大屏页面。

后台现在会提示「有未发布变更」以及尚未关联任何专题的 dcell 数量。已发布 HTML 返回 `Cache-Control: no-store`，避免浏览器继续展示旧导航。注意新 dcell 不会因为上传 ZIP 就自动进入专题导航，这避免把未审核数据直接公布。

## 开箱即用公共模板（V0.4）

不需要 HTML，也不需要使用 GrapesJS。当前内置四套统一设计、随主题配色变化的 dcell 模板：

- **数据集概览**：摘要、指标卡、分类柱形统计、研究说明
- **指标看板**：核心数字、大图表优先
- **图像图集**：代表性图片、图注与相关统计
- **科研成果**：项目简介、科研说明与成果亮点

**最快上手：** 进入后台 `dcell 管理` → `新建 dcell` → `页面来源：公共模板` → 选择模板 → 编辑摘要、指标卡、统计图、研究说明及图片 → `保存基本信息` → `预览模板页面` → 关联专题 → `发布静态站点`。

新建模板模式 dcell 自动附带演示数据，因此不用先做复杂设计就能看效果。演示数据不得作为真实成果使用。

- 内容存放于 SQLite 的 dcell `content` JSON 字段；模板定义在 `template_engine.py`，多 dcell 共用同一套布局规则。
- 更新 `template_engine.py` 后，所有使用对应模板的 dcell 会在**下一次发布**时一起采用新版布局；它们各自填写的数据保持独立。
- dcell 列表新增 `复制`，创建内容副本，再分别修改。
- GrapesJS 和自制 ZIP/服务器目录页面仍可使用，不受模板模式影响。
- 图片先通过模板编辑窗口上传，然后自动追加到图片列表（外部图片 URL 不会被模板自动嵌入）。
- 模板渲染为完整的静态 HTML/CSS，图表目前为 CSS 柱状图，未依赖前台 Python 服务。

模板预览接口：`/api/dcells/<id>/preview`。通用模板列表接口：`/api/templates`。

> 本版的“公共模板”指内置、共享的模板设计定义。尚未做完整的可视化模板库管理和用户自建模板功能；批量 CSV/Excel 导入也还没实现。修改公共模板代码需要重启服务，并重新发布。

## V0.5 源码工作台

在 `dcell 管理` 的每个条目中点击 **源码**：

- **公共模板 / GrapesJS 页面**：直接查看当前生成的完整 `index.html`（只读），支持复制源码或导出 ZIP。点击「转为独立页面并编辑」后生成 `index.html`、`style.css`、`app.js`，此 dcell 由模板模式切换到独立页面模式；其它使用同一模板的 dcell 不受影响。
- **独立 ZIP 页面**：左侧展示页面包内文件树，选择 `index.html`、`style.css`、`app.js` 等 UTF-8 文本文件直接编辑；支持保存、预览、导出可重新导入的 ZIP。Ctrl+S 保存文件，Tab 插入空格。
- **导出 ZIP**：打包完整页面及本地媒体资源，可移交他人或交给 AI 修改，再通过原有「挂载独立页面」导入。页面包文件地址保持相对路径。
- **编辑与发布分离**：源码保存后可通过「预览页面」检查，正式大屏仍需要点击「发布静态站点」才更新。

现阶段源码编辑器是原生文本编辑区，带文件列表、未保存提示、复制、快捷键，尚未集成 Monaco / CodeMirror 的语法高亮，也未做逐键实时预览。源文件限制单个 UTF-8 文本文件 1MB；页面包总体仍沿用 ZIP 文件数及容量限制。不要把不可信第三方 JavaScript 上传到用于管理的同源站点。

## V0.6 单管理员与历史回滚

后台仍保留三个入口。新功能位于 **外观设置 → 管理与历史恢复**。

- 每次专题/dcell 更新、页面包导入、源码保存、关系调整及静态发布前，创建含 SQLite、`data/packages` 和 `published` 的 **操作前检查点**。保留最近 **15** 份，位于 `data/history/`。
- 管理操作日志写入 `data/history/events.jsonl`，不随恢复而覆盖。可在后台查看最近操作、时间、接口、状态及对应检查点。手动创建恢复点也受支持。
- 恢复历史版本前，系统会再保存当前状态作为**救援恢复点**。恢复后数据库、页面包、已发布文件回到目标版本；可再次恢复救援点。
- 管理的媒体文件 `data/media` 为追加式保留，**不会在恢复时删除或回退**；这避免历史图片链接失效，但不等于完整文件系统备份。
- 为避免后台被误操作，**发布、删除、历史恢复**要求输入单一管理员密码进行二次确认。只有一个管理员身份，不含审批或多角色体系。
- 保存成功时后台显示覆盖窗口的彩纸动画与大号结果提示；用户系统设置了减少动画时则使用静态反馈。

本地启动方式（密码仅在当前 shell 会话有效）：

```bash
cd ~/Project/NexVain
micromamba activate nexvain
read -rsp '设置 NexVain 管理员密码: ' NEXVAIN_ADMIN_PASSWORD; echo
export NEXVAIN_ADMIN_PASSWORD
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

浏览器访问 `/admin` 时通过 HTTP Basic 登录（用户名默认 `admin`），发布、删除、回滚时再次输入相同密码。未设置 `NEXVAIN_ADMIN_PASSWORD` 时，**发布、删除、恢复操作被拒绝**，普通的本地编辑仍允许。正式远程使用应配置 HTTPS，避免在明文 HTTP 上发送密码。

恢复快照保存在当前磁盘，不是异地备份，也不支持多进程/多服务器同时修改；建议继续保留定期的整个 `data/` 目录离线备份。当前恢复策略面向本地单管理员、单服务进程的工作站部署。

## V0.8–V0.9 展示及发布收尾（2026-11-02）

- **发布前资源检查**：生成临时发布目录后检查 HTML 中的本地图片、脚本、样式表、iframe 以及 CSS 的 `url()` / `@import` 引用；缺失时返回 HTTP 409 和具体文件路径，不覆盖原有 `published/`。静态引用检查不是浏览器动态运行测试，不会识别 JS 在运行时拼接的请求 URL。
- **历史恢复增强**：先在临时目录解压并验证 SQLite，准备目录切换；发生捕获到的恢复异常时尝试回退目录和数据库。恢复前仍创建救援检查点。突然断电、损坏磁盘或多进程并发不属于完全事务性保证。
- **源码即时预览**：dcell 的「源码」窗口提供 `iframe` 沙箱临时预览。HTML、CSS、JS 的未保存内容可以先预览，点击保存才实际更新页面包。
- **排序**：「专题管理」卡片可拖拽调整顺序；编辑专题时可拖动其 dcell 行并点击「保存关联及排序」，然后静态发布。
- **素材库**：模板内容编辑页可查看已上传图片、选择图片自动写入图集内容。素材 API：`GET /api/assets/library`。
- **大屏交互**：发布页面右下角「全屏」「轮播」控件；F 键切换全屏、左右方向键翻页、空格开始/停止每 12 秒轮播。也可以给页面 URL 加 `?autoplay=1`。纯静态页面运行，不需要后台 API。
- **1920×1080 Chromium 验收**：`scripts/visual_smoke.py` 用真实 Chromium 对首页、专题页、指标 dcell 进行横向溢出检查、导航与标题可见性检查，并生成三张 1920×1080 浏览器截图；GitHub Actions 工作流 `1920 Visual smoke` 运行并上传截图。这个结果覆盖这三类样例，不能替代所有自定义 ZIP 页面的人工逐页审查。
- **开发模式**：服务端 `NEXVAIN_DEV_MODE=1` 仅在本机请求下关闭密码验证，权限后端回归测试通过；后台二次确认弹窗仍需手动留空点击确认，前端尚未完全实现免弹窗。本模式不要绑定公网或置于公网反向代理之后。

本地运行仍使用 `python -m uvicorn app:app --host 127.0.0.1 --port 8000`。需要图片和自定义脚本的 ZIP 请保证在发布包里使用相对路径。启动后进入 `/admin`，相关功能继续归属原有三个管理入口，不增加第四个菜单。

## 固定 1920×1080 嵌入展示（最新）

NexVain 是上级系统中的固定画布模块。专题首页和 dcell 外层展示页面统一固定为 **1920×1080**，左导航宽 300px，右内容区宽 1620px。内部内容过长时在展示区滚动；窗口尺寸变化不会导致布局重新换行成移动端模式。已移除全屏、轮播、自动跳页和键盘翻页控件。较小的宿主容器应由上级系统自行裁切或按比例缩放整个 iframe。旧版文档中提到的全屏与轮播操作均已废止。
